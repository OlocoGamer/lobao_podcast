# Lobão Podcast — site

Site estático, responsivo e sem dependências externas.

## Páginas
- `index.html` — página inicial e próximos jogos.
- `zerados.html` — arquivo de jogos zerados, com busca e reviews.
- `sobre.html` — apresentação do podcast e integrantes.

## Navegação
A navegação superior leva para páginas separadas de Próximos jogos, Jogos zerados e Sobre.

O botão "Editar conteúdo" da página inicial foi removido. O painel `⚙ Painel ADM` continua disponível para gerenciar os dados.

## Dados
Os dados continuam em `data.js`. Alterações feitas pelo painel ficam salvas no `localStorage` do navegador.
